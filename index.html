Passo a Passo: Link Sempre Online + Atalho no iPhone

PASSO 1 — Gerar seu Link Sempre Online (Grátis no GitHub Pages)
  1. No seu GitHub, crie um repositório chamado tunevibe-web (ou use uma pasta docs/ no seu repositório atual).
  2. Baixe este arquivo Web (index.html) e envie para a raiz desse repositório.
  3. No GitHub, clique em Settings → Pages, em Branch escolha main e clique em Save.
  4. Pronto! Em 1 minuto o GitHub gera seu link fixo 24h no ar: https://seu-usuario.github.io/tunevibe-web/
PASSO 2 — Instalar como Aplicativo na Tela de Início do iPhone
  1. Abra o link no navegador Safari do iPhone.
  2. Toque no botão Compartilhar (ícone do quadrado com seta para cima ⬆️ na barra inferior do Safari).
  3. Role para baixo e toque em "Adicionar à Tela de Início" (Add to Home Screen).
  4. Toque em Adicionar no canto superior direito. O ícone vermelho do TuneVibe vai aparecer junto com os aplicativos do iPhone e abrirá em Tela Cheia sem barra de endereço!
